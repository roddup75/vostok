# Crypto Rebalance Strategy

This directory contains a standalone workflow for cross-sectional long/short prediction research across two asset classes:

- `crypto`: real or cached crypto OHLCV data
- `equity`: bundled synthetic monthly equity factor data generated by the companion `equity_backtester` project

The workflow supports:

- Rebalance crypto every `3D` or `7D`, and equity monthly
- Refit crypto models monthly and equity models monthly or quarterly
- Predict crypto forward returns at `1`, `3`, or `5` day horizons, and equity forward returns at `1` or `3` month horizons
- Use a rolling estimation window in months, for example `6` months
- Start with a broader default universe of 30 crypto assets, while remaining fully configurable
- Construct a default `5` long / `5` short market-neutral book from the forecast ranks
- Build a large technical-indicator feature matrix across multiple windows
- Add shared BTC and ETH benchmark regressors, including lagged daily and weekly returns
- Transform asset-specific features cross-sectionally by date using rank-to-uniform then inverse-normal scaling
- Predict beta-adjusted forward residual returns versus BTC and ETH
- Size positions by inverse volatility and neutralize them to cash, BTC beta, and ETH beta
- Train and compare rolling Elastic Net, XGBoost, and DDPM models with hyperparameter search
- Construct long/short portfolios from top and bottom forecasts
- Produce prediction and portfolio metrics, including information coefficient, for all models
- Generate charts plus a LaTeX report and optional PDF

For equity runs, the target is forward stock return minus the equal-weighted universe forward return for the same month, so performance is measured on market-relative return. The equity book is long the top 20% of forecasts and short the bottom 20%, equal-weighted within each side by default, with quarterly model refits. The bundled synthetic equity panel is stored under `crypto_rebalance_strategy/equity_data/synthetic_factor_1000x360_20260905/` as two compressed Parquet parts to keep the project self-contained while avoiding a single oversized Git file.

## Quick Start

1. Install project dependencies from `requirements.txt` in this directory.
2. Download and cache real Binance spot OHLCV data through `2026-09-03`:

```bash
python -m crypto_rebalance_strategy.download_real_data \
  --provider binance \
  --start-date 2021-09-01 \
  --end-date 2026-09-03 \
  --output-dir crypto_rebalance_strategy/real_data_binance
```

3. Run the backtest on the cached real dataset:

```bash
python -m crypto_rebalance_strategy.cli \
  --asset-class crypto \
  --data-dir crypto_rebalance_strategy/real_data_binance \
  --start-date 2021-09-01 \
  --end-date 2026-09-01 \
  --rebalance-frequency 7D \
  --horizon 5 \
  --train-window-months 6 \
  --model-refit-frequency M \
  --output-dir crypto_rebalance_strategy/output
```

You can also pull live data directly without a local cache:

```bash
python -m crypto_rebalance_strategy.cli \
  --asset-class crypto \
  --provider binance \
  --start-date 2021-09-01 \
  --end-date 2026-09-01
```

Run the equity workflow on the bundled synthetic factor panel:

```bash
python -m crypto_rebalance_strategy.cli \
  --asset-class equity \
  --equity-universe-size 1000 \
  --rebalance-frequency M \
  --model-refit-frequency Q \
  --horizon 1 \
  --train-window-months 60 \
  --output-dir crypto_rebalance_strategy/output_equity
```

The default equity data path points to `crypto_rebalance_strategy/equity_data/synthetic_factor_1000x360_20260905/equity_model_panel_parts`, so `--equity-data-path` is only needed when testing an alternate panel.

Local OHLCV CSV files should be named like `BTC-USD.csv` and contain:

- `date`
- `open`
- `high`
- `low`
- `close`
- `volume`

`real_data_binance/` now contains a real daily spot OHLCV cache for the 30-asset universe, downloaded from Binance on `2026-09-03`.

## Output

The run writes into the chosen output directory:

- `predictions.csv`
- `portfolio_returns.csv`
- `summary_metrics.json`
- `plots/`
- `report/report.tex`
- `report/report.pdf` if `pdflatex` is installed
